# Python-Programming-Assignments

Python programming assignments and practical programs organized unit-wise.

## Units

-Unit 1 - Python programming foundations, data structures and functions

-Unit 2 - Control Structures, Iteration and Intermediate Python Concepts

-Unit 3 - Modules, Packages, Standard Libraries and Regular Expressions

-Unit 4 - Object-Oriented Programming and File Handling Object-Oriented Programming in Python

-Unit 5 - Exception Handaling, Data Analysis and Database Connectivity
